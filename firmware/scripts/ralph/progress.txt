## Codebase Patterns
- Entity globals are in `ui/data.h` + `ui/data.c` (Badge, Machine, Tank, g_badges, g_machines, g_tanks, g_badge_count, etc.)
- The build environment requires IDF_PATH setup; source /Users/I584748/esp/esp-idf/export.sh before idf.py
- Pre-existing CMake issue: `gdbinit.cmake:40` fails with "exactly three arguments" error; does not affect compilation
- Build: `idf.py build` fails with cmake 4.3.2; use direct riscv gcc compile from compile_commands.json to verify individual files
- LVGL is pinned to CPU1 (task_affinity=1 in bsp_display_cfg_t); all other tasks (sim, mqtt, btn, console) should use CPU0 or auto
- LVGL draw buffers MUST stay in internal DMA-capable SRAM (buff_spiram=false, buff_dma=true); buff_spiram=true causes UI freeze
- Screenshot tool: python3 tools/screenshot.py from firmware/ dir
- THREAD SAFETY RULE: Any code running outside the LVGL task (sim_task, mqtt event handler, wifi event handler) must NEVER call LVGL APIs directly. Use lv_async_call() trampolines.
- DATA MUTEX: g_machines and g_tanks are shared between sim_task (CPU0, writes) and LVGL refresh timers (CPU1, reads). Protect all reads/writes with DATA_LOCK()/DATA_UNLOCK() macros.
- LVGL TASK STACK: Set cfg.lvgl_port_cfg.task_stack = 20480 in bsp_display_cfg_t init.
- Flash to device: idf.py flash (port auto-detected as /dev/cu.usbmodem5B610403841)
- Serial monitor requires TTY; use python3 -c with pyserial for headless capture instead of idf.py monitor
- SimProfile enum is in main/ui/data.h: { SIM_RANDOM_WALK = 0, SIM_SINE, SIM_RAMP, SIM_STEADY }
- sim_task.c: sim_metric() dispatches on m->sim_profile; metric_push() is only called when profile != SIM_STEADY
- ui_detail.c: s_ctx_tank / s_ctx_machine / s_ctx_metric back-references are used to write values back to the live Metric struct
- ui_detail.c: rand_h = 112 is the height reserved for the random generator section (to be replaced by s_sim_panel)
- ui_detail.c: viz_h calculation: DETAIL_H - SZ_GAP*2 - hdr_approx - SZ_BTN_SM - rand_h - SZ_GAP*4 — must be updated when rand_h changes
- Metric struct (ui/data.h): sim fields are sim_profile, sim_amplitude, sim_period_s, sim_offset, sim_phase_acc, rand_min, rand_max, step
- Direct compile check: riscv32-esp-elf-gcc <flags from compile_commands.json> main/ui/ui_detail.c
